# movies.js

This is a fork of [x8r's movie api](https://github.com/x8rr/movies), written in a single JavaScript file made for pnpm (Cloudflare Workers).

## Installation:
Download [/src/worker.js](https://github.com/hiwa1do/movies.js/blob/main/src/worker.js)

Go to Cloudflare Workers & Pages

Click "Create Application", "Start with Hello World!", then "Deploy"

Select all of the code in the box and replace it with the code from worker.js

Click deploy and your all done
